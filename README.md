# Hypr Cookie Clock & Lock Rice

Personal Hyprland setup — an Android 17 / Material You "cookie" clock on the
desktop (`widget-clockana`) and on the hyprlock lockscreen
(`lockclockana` + `lockscreen-style`), all colours synced from the wallpaper
accent by the single theme engine (`palette.py`).

```
.
├── README.md
├── common/
│   └── widget_lib.py          shared GTK-layer helpers (accent, monitor, one-instance)
├── desktop/
│   └── widget-clockana        live desktop cookie clock (Cairo, 60fps)
├── lockscreen/
│   ├── lockclockana           renders the cookie clock PNG for hyprlock
│   ├── lockscreen-style       lockscreen widget editor + conf generator (SUPER+S)
│   └── lockscreen.json        widget positions/sizes
└── hypr/
    ├── hyprland.lua           main config (keybinds at the bottom)
    ├── hyprland-gui.lua       HyprMod-generated overrides (KEEP: SUPER+E → dolphin)
    ├── rules.lua              window + layer rules  [blur/animations live here!]
    ├── variables.lua          HyprMod-managed variables
    └── hyprlock.conf          generated by lockscreen-style
```

## Changelog — 2026-09-26 update

### Desktop cookie clock (`widget-clockana`)
- Faithful port of **end-4/dots-hyprland** "cookie" / Android-17 analog clock
  (rebuilt from the real QML/JS sources: `Config.qml`, `CookieClock.qml`,
  `HourHand.qml`, `MinuteHand.qml`, `TimeColumn.qml`, `MinuteMarks` +
  `rounded-polygon-qmljs`). Exact geometry lives in a 230-unit box and scales
  to any widget size:
  - face = `RoundedPolygon.star(14, 1, 0.8, 1.5/14).rotate(30°)` (Material You)
  - hour hand = rounded capsule, front 62 / tail 10 / width 20, **PRIMARY**
  - minute hand = rounded capsule, front 89 / tail 6 / width 12, **TERTIARY**
    (accent hue + 150°)
- **Look kept minimal (user preference):** digits, dial marks and date bubbles
  were removed — shape + hands only, very slightly translucent
  (face 0.88, hands 0.92).
- Smooth minute/hour glide (`Smooth` class — 0.35 s emphasized ease, wrap-safe).
- Material-You palette derived live from `widget_lib.accent()` (wallpaper):
  `PRIMARY`, `FACE` (primaryContainer), `TERTIARY` etc.

### Blur experiment — REVERTED (important lesson)
A first attempt added
`hl.layer_rule({match={namespace="widget-clockana"}, blur=true})`. Hyprland
blurs the **whole rectangular layer surface**, not the transparent shape, so
the widget became one big frosted square. It was rejected and fully removed.
Do **not** re-add compositor blur on layer-shell widgets.

### Cookie clock on the lockscreen (new)
- `lockclockana` renders the same star + hands as a transparent PNG
  (`~/.cache/lockscreen-clockana.png`).
- `lockscreen-style` gained a **Cookie Clock** entry; it now emits a hyprlock
  `image {}` block with:
  - `reload_time = 5` + `reload_cmd = ~/.local/bin/lockclockana` → the hands
    stay **live while locked** (the PNG is re-drawn every 5 s);
  - `border_size = 0`, `rounding = 0` (transparency already in the PNG).
- Placed with the same anchor rules as the text labels (no negative offsets —
  hyprlock 0.9.x falls back to center otherwise).
- **First run:** open `lockscreen-style` → **Save & Apply** (generates the
  initial PNG + rewrites `hyprlock.conf` with your real monitor size), then
  preview with **SUPER+L**.

### Other fixes in this update
- `build_rounded_polygon` crash fix (a generator was passed as a positional
  argument to `min()`/`max()` → TypeError at import).
- Digit colour-mix direction corrected to match end4
  (`mix(colPrimary, colPrimaryContainer, 0.55)`).

## Notes
- **Terminal shortcut caveat:** `hyprland.lua` binds `SUPER+T`/`SUPER+RETURN`
  to `contour`, but the HyprMod-generated `hyprland-gui.lua` currently
  **overrides** them to `open-foot` (→ `foot`). If you regenerate
  `hyprland-gui.lua` in HyprMod, check this mapping and re-pick your terminal.
- **rules.lua is a live dependency:** `hyprland.lua` loads it via
  `pcall(require, "hyprland.rules")` — without that line all wofi/swaync blur
  & animations silently vanish. After any change: `hyprctl reload`.
- All UI strings/shortcut labels in this rice are intentionally **English**.
- No secrets in this repo. (The Telegram bot with its `BOT_TOKEN` lives
  elsewhere and is NOT included.)
