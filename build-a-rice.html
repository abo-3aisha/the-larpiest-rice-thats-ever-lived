١. الفكرة الكبرى

قبل أي كود، لازم تفهم شي وحدة: الرايس مو رفوف قهوة. هونظام، كل قطعة فيه بتتكلم مع الباقي.

أغلب الناس بتاخد رايس من جيمپ، يعجبها، تنسخ الملفات، وتوقف. بتعيش معه أسبوع وبعدين تلاقي: الشريط أخضر والاNotifications بنفسجي، الأيقونة مشAnimator، وكل script فيه مسار `/home/فلان` مش اسمه.

ليش؟ لأنهم نسخوا النتيجة بدون المنطق.

القاعدة الذهبية: الرايس الكويس عنده مصدر حقيقة واحد (single source of truth).

بتغيّر الخلفية ← كل شي بيتلوّن لحاله. مو إنت اللي بتلوّن — محرك واحد هو اللي.

٢. الطبقات الثمانية

٢.١ المُركِّب — Hyprland

هاد مو theme، هادالمنسّق. هو اللي بيقرر وين كل نافذة، مين شاطر الحSCSI؟ (مو مهم)، وين الـ layer فوق مين.

النقطة اللي بتفرق: Hyprland عنده طبقات (layers) هاد用語 مهم:

الطبقةشو فيهامثال
backgroundأقصى تحتالخلفيات
bottomفوق الخلفيةالـ widgets الزجاجية
topفوق الـ windowsشريط waybar، شريط swaync
overlayأعلى كل شيالقوائم المنبثقة

مهم جداً: الـ blur بـ Hyprland بيشتغل على الطبقات بس (layer rules)، مش على الـ windows. يعني وofi (قائمة overlay) ينblur، بس Dolphin (window) لأ.

هاد مش bug — هيك Hyprland مصمّم. attempting تضيف blur بwindow rule = الهيدرو/API بيرفضها بصمت.

وفكرة ثانية: widgets بتbove الـ windows = سيئة. تصير تحجب اللي عم تشتغل عليه. الحل: خليها bottom layer. هاي الزبدة اللي فهمتها متى طلبت منّي.

٢.٢ الشريط — waybar

waybar ما بيسوي ALU. هو بيعمل exec لسكربت كل X ثواني، والسكربت بيرجّع نص. أنت اللي بتقرر شو يقول.

قوة اللي بتميّزك: ترجّع JSON مش نص، فعندكCSS classes بتتحكم بكل شي:

"exec": "battery-bar.sh",
"interval": 10,
"return-type": "json"     ← JSON مش نص

والسكربت بيرجّع:

{"text":"92%","class":["b100"],"alt":"92 percent"}

هلق بالـ CSS تكتب .b100 { color: #4ade80; } وهاد بينطّق على 100% لحاله. بتخلق موديول كل الحالات بدون ما تعيد تشغيل waybar.

شو الـ tier واللهو؟

مشكلة حقيقية: صورة فيهادرجات كثيرة من لون واحد. صورة جبال بنفسجية فيها ٥٠ ألف紫色 بأشكال مختلفة، بس ما في ولا أزرق. لو سألت "شو اللون"، naïve code بيطلع "أزرق" لأن الـ histogram العام بيطلع غلط.

الحل: طبقات التشبّع. جرّب ٣٠٪، لو ما لقيت، ٢٢٪، لو ما لقيت ١٥٪. صورة حقيقية دايماً بتلاقي سلّة ملوّنة. صورة رمادية فعلاً (أبيض/أسود/فضي) ما بتلاقي ← بترجع أبيض #dfdfdf.

فخ الـ HSL مش HSV: colorsys.hls بيعطي تشبّع أقل من HSV للألوان الغامقة. لو حسبت threshold على أساس HSV ورحت تطبقه على HSL، threshold بتكون غلط بسلّم — والصور الغامقة كلّها بتطلّع باهتة.

ليش الـ"lighter if dark"

if luma(accent) < 0.22:
    accent = lighten(accent)     # ارفع الـ lightness بس خلّي الـ hue

لأن عندي صورة Wine/grenadine غامقة. لو تركتها غامقة، الـ accent بيطلع wine الغامق على الشريط → مش باين. رفعت الـ lightness بس بقي نفس الـ hue → صار أحمر نبيتي واضح. مش بينقلب لـ وردي.

٣.٤ خطوة ٣: الكتابة — و"الشي اللي ما يتغيّر ما يُكتب"

هاي ثانية بذكاء، بسيطة، وبتنقذ وقت:

def diff_write(path, text):
    """اكتب فقط إذا المحتوى تغيّر فعلاً"""
    if path.read_text() == text:
        return False      # ما في تغيير = ما نكتب
    path.write_text(text)
    return True

ليش هاي مهمة؟ لو الـ theme كتب الـ CSS كل مرة:

  • كل برنامج بالـ watch mode بيرى تغيير mtime ← يعيد بناء لحاله
  • كل مرة بانعمل wallpaper تغيّر، الشريط بيطير ويرجع (تشويش)
  • 看不出来 بالضبط شو تغيّر

مع diff_write: نيت ما في rebuild إلا إذا اللون تغيّر فعلاً.

٤. الخلفيات — كيف صارت behaves زي بعض

٤.١ المشكلة الأصلية

بدّيت بـ ٣ سكربتات منفصلة: وحدة للصور، وحدة للفيديو، وحدة للتبديل. وكل وحدة بتعمل أشياء مختلفة عند التركيب.

أهم ٣ أخطاء volcóت段时间:

  1. الtransition ما كانت تنشوف — الفيديو كان فوق الصورة الجديدة، فالأنيميشن محجوب.
  2. الفيديو ما يتحرك — الملف كان ٤K AV1، وجهازك ماعندو decoder للـ AV1، فكلشي يـ software decode ويلخبط.
  3. Extract images مرتين مع timestamps مختلفة — كانت الـ frame للثيم والـ frame للمعاينة.

٦. الفخاخ — الدروس اللي كلّها كلّفتني وقت

هاي الـ ١٢ فخ — كل واحد صار معي. اقرأهم لأنكرح تفوتك نفسهم.

فخ ١: $HOME ما بينفّذ جوّا JSON

waybar، swaync، CSS: كل قيم الـ config بينفّذوا حرفياً. $HOME بتطلع اسم مجلد حقيقي اسمه $HOME!

الحل: غيّر اليوزر نيم ولا تحط $HOME. طلعت هاي من qt6ct.

فخ ٢: Hyprland ما بيحمّل hyprland/ تلقائياً

عندك مجلد hyprland/rules.lua. بس Hyprland مش بيعمل require تلقائياً للملفات اللي جوّا مجلد. فـ rules.lua بتضل ما تُحمّل، وكل blur اختفى بصمت.

الحل: في hyprland.lua:

pcall(require, "hyprland.rules")

ولو HyprMod عمل regen، رجّعها.

فخ ٣: blur ما بيشتغل على الـ windows

Hyprland blur = layer بس. ما بتقدر تحط blur بـ window rule. الـ API بيرفضها بصمت.

الحل: القوائم المنبثقة (wofi, swaync) = overlay layer ← ينblur. الـ apps العادية = windows ← لأ.

فخ ٤: Tiger Lake ما عنده AV1 encode

auto في ffmpeg بختار AV1 (أفضل codec)، وجهازك ما بيقدر يعمل encode بـ AV1. النتيجة: فشل صامت.

الحل: حدد --codec avc صريحاً.

فخ ٥: 4K wallpaper = بطء كل الديسكتوب

صورة 4K AV1 على iGPU بلا decoder ← software decode ← ٤ أضعاف البكسلات لكل فريم ← الديسكتوب كلو ي.cards.

الحل: حوّل لـ 1080p60 مرة وحدة + H.264.

فخ ٦: VFR يخلي الفيديو يتقطّع

فخ ٨: speaker ما بيشتغل + jack مركّب
